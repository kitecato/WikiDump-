WikiDumpMods

A read-only BepInEx plugin for Valheim. It writes everything your installed mods add to the game into JSON and PNG files, so you can document a modpack, check balance or translate mods without reading their code.

  • Thunderstore
  • Nexus Mods
  • ModDB
  • GitHub release

Install and run

  1. Install BepInExPack for Valheim (BepInEx 5.4.x).
  2. Extract the BepInEx folder from the release zip into your Valheim folder, or install the Thunderstore package with a mod manager.
  3. Enter any world and wait about 10 seconds.
  4. Press F11 in a world to dump again, for example after switching the game language.
  5. Read the files in BepInEx/config/wikidump_mods/.

Nothing in your world, character or other mods is changed. The plugin is client-side only, and Jotunn is optional.

What ends up in the folder

items.json
Modded items: names and descriptions per language, stats per quality level, recipes, how to obtain, uses, sets, tooltips.
pieces.json
Modded build pieces and stations, plus vanilla pieces that now need modded materials.
creatures.json
Modded creatures, and vanilla ones that drop or eat modded items: health, resistances, attacks, drops, spawns, taming.
recipes.json
Every recipe that makes or needs modded items or stations.
world.json
Spawns, events, locations and dungeon rooms with modded content.
vanilla_changes.json
Vanilla values your mods changed: recipes, drops, trader stock, stats.
origin.json
Which mod owns each object, and the evidence for that verdict.
localization/
Translation tables, per-mod translations with the source of each line, and missing translations.
icons/
PNG icons of items (all variants), pieces, status effects, skills and each mod's own icon.
mods.json, mods/
Per plugin: version, Thunderstore manifest, README, config entries, Harmony patches, asset bundles.

How it decides which mod added what

An object counts as modded when one of these says so: Jotunn's mod registry, item and piece manager libraries, an asset bundle shipped with a mod (matched by object identity, not file name), or a difference from the built-in vanilla baseline. Every verdict is written to origin.json together with its evidence, so you can check it yourself.

Drop chances follow the game's own drop-table logic: table chance, roll count, weights and one-of-each.

Vanilla baseline

The plugin ships with a snapshot of unmodded Valheim 1.0.16. After a game update you can build a fresh one: disable every mod except BepInExPack, WikiDumpMods and Jotunn, enter a world and wait for the baseline message. The new file is vanilla_baseline.jsonl.gz, and a local baseline takes priority over the built-in one.

Config

The file is BepInEx/config/ua.valheimwiki.wikidumpmods.cfg. Main options and their defaults:

AutoDump = true
Dump once per session after you enter a world.
Hotkey = F11
Press in a world to dump again.
DelaySeconds = 10
How long to wait after the player spawns, so other mods can finish registering.
Languages = English,Ukrainian
Translation tables and tooltips to export. The current game language is always included.
Icons = true
Save PNG icons of modded content.
IconColorMode = LinearToSRGB
Exact colour correction for icons. sRGB and Linear also exist; change it only if icons look wrong.
ScanVanillaLocations = true
Open vanilla locations and dungeon rooms to find modded items placed in them. Slower.
IncludeVanilla = false
Export vanilla content too, for a full game dump instead of mods only.
Tooltips = true
Export the game's own tooltip text per language.
RawDepth = 4
Nesting depth of the raw prefab dump in raw/.

IconColorMode matters because Valheim runs in linear colour space. Icons saved without the conversion come out too dark.

Source and compatibility

The code is on GitHub, with a build.sh that compiles the plugin. It is tested on Valheim 1.0.16 with BepInEx 5.4.23.

The output has the same shape as the data behind Valheim Wiki, an English and Ukrainian wiki built from the game's files.
