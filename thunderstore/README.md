# WikiDumpMods 1.0.4

Плагін BepInEx лише для читання. Вивантажує все, що встановлені моди додають у Valheim, у `BepInEx/config/wikidump_mods/`. Світ, персонаж і інші моди не змінюються. Працює поруч із WikiDump: інша папка й інша клавіша.

## Запуск
1. Імпортуй `WikiDumpMods_1.0.0_thunderstore.zip` у r2modman (Settings → Profile → Import local mod).
2. Зайди в будь-який світ і зачекай ~10 с. По центру з'явиться «WikiDumpMods: готово». Повторний дамп: **F11**.
3. Надішли архів папки `BepInEx/config/wikidump_mods/` разом з `BepInEx/LogOutput.log`.

## Ванільний еталон
Усередині плагіна вже є еталон ванільної гри 1.0.16 (зібраний з дампу WikiDump без модів). Завдяки йому поділ на модове й ванільне точний для предметів, будівель, істот, рецептів, ефектів, локацій і подій, а `vanilla_changes.json` показує, що моди змінили у ванілі.

Власний еталон потрібен лише після оновлення гри: вимкни всі моди, крім BepInExPack, WikiDumpMods і Jotunn, зайди у світ і дочекайся «збережено ванільний еталон» (`vanilla_baseline.jsonl.gz`). Він має пріоритет над вбудованим.

## Файли
| Файл | Що всередині |
|---|---|
| `manifest.json` | версії, мови, кількості, час кожного розділу, помилки |
| `mods.json` | кожен плагін: версія, Thunderstore-маніфест, README/CHANGELOG, усі налаштування (значення, типові, опис), Harmony-патчі, AssetBundle, статичні дані з коду, список вмісту |
| `mods/<guid>.json` | короткий список вмісту одного мода |
| `items.json` | модові предмети: назви й описи всіма мовами, іконки, характеристики по рівнях якості, рецепти з вартістю кожного рівня й рівнем станції, де взяти, де використовується, сет, статус-ефекти, підказки з гри, повні дані |
| `pieces.json` | модові будівлі й станції + ванільні, що тепер вимагають модові матеріали: чим будується, матеріали, затишок, що крафтиться на станції, розширення |
| `creatures.json` | модові істоти + ванільні, що тепер дропають/їдять модові предмети: здоров'я, стійкості, спорядження й атаки, дроп, де спавняться, ШІ, приручення, розмноження |
| `status_effects.json` | модові ефекти: назви, опис, підказка з гри, іконка, хто їх дає, усі поля |
| `recipes.json` | усі рецепти, що створюють/вимагають модове або на модовій станції |
| `world.json` | спавн модових істот (біом, день/ніч, рівні), події, локації й кімнати підземель з модовим вмістом (з шансом появи) |
| `vanilla_items_linked.json` | ванільні предмети, які моди дали нові способи отримати чи використати |
| `vanilla_changes.json` | ванільні значення, змінені модами: дроп, рецепти, торговці, характеристики |
| `references.json` | будь-які інші посилання на модовий вміст у полях об'єктів гри |
| `origin.json` | чому кожен об'єкт вважається модовим і чий він |
| `raw/<guid>.json` | сирий дамп усіх компонентів модових префабів |
| `localization/` | повні таблиці мов, переклади кожного мода з джерелом кожного рядка, `missing_translations.json` |
| `icons/<guid>/...` | PNG-іконки предметів (усі варіанти), будівель, станцій, ефектів, навичок + іконка мода |

Шанс у скринях (`chanceAny`) рахується за логікою гри (шанс таблиці, кількість кидків, вага, `oneOfEach`). Шанс появи самої скрині в локації — окреме поле `presenceChance`.

## Переклади модів
Плагін бере текст спершу з гри, а якщо гра його не дає — з файлів перекладу: `*.yml`/`*.json` у `BepInEx/config` (наприклад, `TherzieTranslations/Warfare/Warfare.Ukrainian.yml`; ці мають найвищий пріоритет), у папці мода, усередині DLL мода, а також з бібліотек LocalizationManager / ItemManager / PieceManager і Jotunn. Звідки взято кожен рядок, видно в `localization/mod_<guid>.json → source`.

## Налаштування (`BepInEx/config/ua.valheimwiki.wikidumpmods.cfg`)
| Ключ | Типово | Що робить |
|---|---|---|
| `AutoDump` | `true` | дамп раз за сесію після входу у світ |
| `Hotkey` | `F11` | повторний дамп |
| `DelaySeconds` | `10` | затримка перед автодампом |
| `Languages` | `English,Ukrainian` | мови таблиць і підказок |
| `Icons` | `true` | зберігати іконки |
| `IconColorMode` | `LinearToSRGB` | міняти лише якщо іконки вийдуть неправильних кольорів (`sRGB`, `Linear`) |
| `ScanVanillaLocations` | `true` | шукати модові предмети/істоти у ванільних локаціях (повільніше) |
| `IncludeVanilla` | `false` | вивантажити й ваніль (повний дамп гри) |
| `Tooltips` | `true` | підказки з гри для кожного рівня якості |
| `ModStaticData` | `true` | статичні дані з коду модів |
| `RawDepth` | `4` | глибина сирого дампу |
| `ForceBaseline` | `false` | записати еталон, навіть якщо лишились інші плагіни (лише якщо вони не додають вмісту) |
